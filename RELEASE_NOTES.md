# Vluxio WLED Add-on 1.6.1 beta

First public test version. The package is `local.vluxio.freeathome-wled-1.6.1.tar`.

This beta adds a native **Add controller** settings group, automatic WLED segment reconciliation, NL/DE/EN settings text and Vluxio branding. The artwork is included in the package; it does not yet appear on the SysAP add-on tile.

Build, metadata validation and 28 automated tests passed. The add/remove controls have been observed on one SysAP. Testing with multiple real controllers, existing free@home links and scenes, segment changes and SysAP CPU/RAM use is still required. The four-controller limit is provisional. Back up the SysAP before installing this beta.
